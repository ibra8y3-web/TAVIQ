# TAVIQ Logo Assets

The logo is procedurally authored geometry, not an AI-generated image.

- `taviq-mark.svg`: vector mark.
- `taviq_3d_logo.py`: Blender Python script that constructs a beveled metallic 3D emblem and 3D wordmark, sets lighting/camera, and renders a PNG.
- Run with Blender: `blender -b -P taviq_3d_logo.py`.
- Output: `taviq-3d-logo.png` in this directory.

The Blender script is source; the rendered PNG and editable `.blend` file are generated on the machine running Blender.
