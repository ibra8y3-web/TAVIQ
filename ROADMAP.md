# TAVIQ Roadmap

Status vocabulary: `implemented`, `in progress`, `specified`, `not started`.

| Stage | Scope | Initial status |
|---|---|---|
| 01 | Foundation, license, build, repository policy | implemented |
| 02 | Lexer, parser, AST, source diagnostics | prototype implemented |
| 03 | Static type system and semantic analysis | specified |
| 04 | Typed TAVIQ IR and verifier | specified |
| 05 | QVM bytecode and runtime | not started |
| 06 | Native compiler backend (LLVM) | not started |
| 07 | Core runtime and platform abstraction | not started |
| 08 | Native AI engine and provider adapters | specified |
| 09 | Parallel and accelerator computing | specified |
| 10 | Sandbox and capability security | specified |
| 11 | Standard library | not started |
| 12 | Package manager and registry | specified |
| 13 | CLI, formatter, linter, debugger, profiler | CLI prototype only |
| 14 | Windows/Linux/macOS/Android targets | not started |
| 15 | TAVIQ Studio IDE | specified |
| 16 | Release engineering and stable release | not started |

A stage may be marked implemented only when its acceptance tests pass and its
documentation describes actual behavior.
